# Gündəlik Oxu — 청소년 하루 한 장 성경읽기

학생 페이지: `https://skyazery.github.io/m-dersleri/oxu/?k=학생키`
(키 없이 열면 '견본' 화면이 나오고, 전송은 되지 않습니다. `?f=5`를 붙이면 5장을 미리 볼 수 있습니다.)

## 구성
- `index.html` 학생 화면 (아제르바이잔어). 본인 진도대로 다음 장이 열림
- `ayarlar.js` 설정 파일. **Apps Script 주소를 여기에 넣기**
- `data/matta-metn-01-10.json` 마태복음 1~10장 본문 (holybible.or.kr 원문 그대로)
- `data/matta-oyrenme-01-10.json` 장별 소개·퀴즈·묵상 질문과 단어 사전
- `apps-script/Code.gs` 구글 시트·텔레그램 연결 스크립트

음성은 각 장의 IBT 사이트 페이지로 연결되는 "Səsli dinlə(듣기)" 버튼으로만 제공합니다.

## 처음 한 번 설정 (약 15분)

### 1. 텔레그램 봇 만들기 (수학 봇과 별도)
1. 텔레그램에서 **@BotFather** 검색 → `/newbot`
2. 이름 예: `Gündəlik Oxu`, 아이디 예: `gundelik_oxu_bot`
3. 받은 **토큰**(긴 숫자:문자열)을 복사
4. 새 봇을 열고 아무 메시지나 한 번 보내기 (예: "salam")

### 2. 구글 시트 만들기 (수학 시트와 별도)
1. 새 구글 시트 만들기 → 이름 예: `성경읽기 학생관리`
2. 메뉴 **확장 프로그램 → Apps Script**
3. 기본 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여 넣기 → 저장
4. 시트로 돌아와 새로고침 → 위쪽에 **📖 성경읽기** 메뉴가 생김
5. **1) 처음 설정** 클릭 (처음에 권한 승인 창이 나오면 허용)
6. [설정] 탭 `BOT_TOKEN`에 토큰 붙여 넣기
7. **2) 텔레그램 채팅 ID 찾기** → 나온 숫자를 `CHAT_ID`에 붙여 넣기
8. **3) 텔레그램 연결 확인** → 텔레그램에 "연결 성공" 메시지가 오면 OK

### 3. 웹 앱으로 배포
1. Apps Script 화면 오른쪽 위 **배포 → 새 배포**
2. 유형: **웹 앱**
3. 실행 사용자: **나**, 액세스 권한: **모든 사용자**
4. 배포 → 나온 주소(`https://script.google.com/macros/s/…/exec`) 복사
5. 이 주소를 `oxu/ayarlar.js`의 `SCRIPT_URL: ""` 따옴표 안에 넣기

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영됩니다. 이렇게 하면 주소는 그대로입니다.

### 4. 학생 등록
1. [학생] 탭에 **이름**, **전화번호**(예: 595123456)를 적기
2. 메뉴 **학생 키·링크 만들기** → 키, 개인 링크, 왓츠앱 "보내기" 링크가 생김
3. "보내기"를 누르면 학생에게 보낼 메시지가 왓츠앱에 열림 → 전송

### 5. 매일 현황 알림
메뉴 **매일 저녁 현황 알림 켜기** → [설정] 탭의 `알림 시각`(기본 21시)에 "오늘 읽은 학생 / 안 읽은 학생 / 2일 이상 쉬는 학생"이 텔레그램으로 옵니다.

## 학생이 "Oxudum və göndər(읽었어요)"를 누르면
- [읽기기록] 탭에 날짜, 장, 퀴즈 점수, 묵상 글, 질문이 저장됨
- [학생] 탭의 `마지막 장`이 올라가고, 다음 장이 열림
- 선생님 텔레그램으로 메시지 도착
- 이미 읽은 장은 다시 읽고 보낼 수 있음 (기록에 "다시 읽음" 표시)
- 보내려면 퀴즈 3문제에 답하고 묵상 글을 한 문장(10자) 이상 써야 함
