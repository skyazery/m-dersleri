# 교재 생성기

- `dersler/matta-NN.json` : 과별 내용 (한국어·아제르바이잔어 × 어린이·청소년 + 교사용)
- `python3 _src/build.py [과번호…]` : 학생용 4종(`matta-NN-az`, `-az-genc`, `-ko-usaq`, `-ko-genc`) + `muellim/matta-NN/` + 목차 생성
- `python3 _src/ses.py matta-NN-az matta-NN-az-genc` : 아제르바이잔어 음성(mp3) 생성 (바뀐 문장만)
- 그림: `img/nt/` PPT 그림 46장(`siyahi.json`에 구절 목록), `img/matta/` 새로 만든 그림
- 글 표기: `[[낱말]]` 사전 버튼, `[[보이는말|사전키]]`, `{{참조 구절}}`, `**굵게**`
